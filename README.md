# 快速看财报工具 `quick_report.py`

输入股票代码或名称，一键输出「财报速览 + 三表明细（同比 / 环比）」。
数据源：**同花顺官方 hithink-finance**（财报 / 行情 / 估值）+ **东方财富**（券商研报，免 key）。

## 特性

- **总览模式**：行情快照、估值（PE/PB/PS/PCF）、利润表速览+同比、五类财务指标（成长/盈利/偿债/营运/现金流）、最近 8 条券商研报
- **三表明细**：利润表 / 资产负债表 / 现金流量表，按"科目 × 历史多期"透视，附带 **同比** 与 **环比**
- **环比算法**：
  - 利润表 / 现金流（累计口径）→ 用"单季 = 本期累计 − 上期累计"推导真实单季再算环比
  - 资产负债表（时点口径）→ 本期期末 vs 上期期末
- **自动派生字段**：毛利、毛利率、研发费用率（利润表）；资产负债率（资产负债表）
- **代码 / 名称双输入**：`600941` 或 `中国移动` 都能识别，自动消歧
- **健壮性**：429 限流指数退避重试；财务指标滞后时自动回退到最近可用报告期；兼容年报 `FY` 字段
- **概念板块**：查个股所属概念/行业板块，点开某板块看**全部成分股**（代码/名称/最新价/涨跌幅/总市值/PE/PB，按市值降序）
- **因子画像**：把巴菲特/格雷厄姆/林奇/费雪关注的指标提炼为 A 股口径因子（ROE持续性/自由现金流/负债率/PEG/研发率/毛利率），雷达图 + 因子卡 + 同业参照

## 环境与依赖

- Python 3.8+（本机 3.12.4）
- 依赖：`requests`（必需）、`tabulate`（可选，美化表格）
- 平台：Windows / macOS / Linux 均可

## 配置 API Key（一次即可）

同花顺官方 API Key，三种配置方式（优先级从高到低）：

1. **环境变量**：`HITHINK_FINANCE_API_KEY`
2. **本地配置文件**：本文件同目录 `hithink_config.json`
   ```json
   { "api_key": "sk-fuyao-xxxx" }
   ```
3. **运行时输入**（getpass，不回显）

> ⚠️ `hithink_config.json` 含明文 Key，已在 `.gitignore` 中排除，**不要提交到 Git**。

## 用法

```bash
# 总览（默认）
python quick_report.py 600941
python quick_report.py 中国移动

# 三表明细
python quick_report.py 600941 -t income       # 利润表
python quick_report.py 600941 -t balance      # 资产负债表
python quick_report.py 600941 -t cashflow     # 现金流量表

# 总览 + 三表明细一次出
python quick_report.py 600941 -t all

# 指定历史期数（1-20，默认 6）
python quick_report.py 600941 -t all -n 8

# 三表明细口径（默认单季，每列3个月可比；不混尺度）
python quick_report.py 600941 -t income              # 单季 QoQ（默认）
python quick_report.py 600941 -t income -s h1        # 仅历年 H1，同比=去年同期
python quick_report.py 600941 -t income -s fy        # 仅历年年报，同比=去年同期
python quick_report.py 600941 -t balance -s all      # 资产负债表期末快照（默认）

# 概念板块
python quick_report.py 600941 -t concept             # 所属概念/行业板块列表
python quick_report.py 600941 -t concept -b 714      # 某板块(BK0714=5G概念)成分股
```

## 财报分析平台（Streamlit）

除了命令行，还提供交互式 Web 平台（推荐日常使用）：

```bash
streamlit run report_platform.py
# 浏览器打开 http://localhost:8502
```

- 左侧搜索框输入**代码或名称**，右侧 6 个 Tab：总览 / 利润表 / 资产负债表 / 现金流量表 / 概念板块 / 券商研报
- **概念板块 Tab**：展示个股所属全部概念/行业板块（概念排前），下拉选某板块 → 出该板块**全部成分股**（最新价/涨跌幅/总市值，✅标记本股，按市值降序）；上方有**类神经网络概念网络图**（成分股→概念→本股 三层节点图，可拖拽/缩放/悬浮，勾选多概念看交叉成分股）
- **因子画像 Tab**：把大师关注点提炼为 A 股因子——6 张因子卡（ROE持续性/自由现金流/负债率/PEG/研发率/毛利率，各带「关注来源」+「为什么看它」）+ 因子强度雷达图（盈利质量/成长/价值/质量/安全）+ 营收×净利矩阵 + 风险扫描 + 同板块估值参照（PE/PB 中位数 vs 本股）
- **中英双语**：专业名词（科目、指标、行情、Tab）均带英文，方便对照国外资料
- **同口径对比**：利润/现金流是累计口径，混排会失真 → 默认「单季」(每列3个月可比)，可切换「中报 H1」「年报 FY」看同口径同比；资产负债表为时点快照默认「期末全部」
- **图表优先**：总览含 单季动能、中报同口径同比、毛利率/净利率趋势、费用率趋势 4 张图；三表 Tab 图表演示在前、明细表折叠可展开
- 总览：行情、估值、收入利润图表、财务指标折叠面板（双语）
- 三表：关键科目柱状图 + 比率趋势 + 同口径科目×历史期明细（带同比/环比列），可调整历史期数；**明细表下拉选「科目」→ 自动出该科目折线图**（默认营业收入，切换即时刷新）
- **研报可读**：下拉选研报条目 → 出摘要段落（前600字），可**去重下载 PDF**（存 `reports/研报/`，已下载不重复）
- 图表时间轴统一**旧→新（左→右）**，不误导判断
- 取数已做缓存（避开同花顺调用配额），同一股票重复看不会重复调接口

## 数据源说明

| 数据 | 来源 | Key | 说明 |
|---|---|---|---|
| 行情 / 估值 / 三表 / 财务指标 | 同花顺 `fuyao.aicubes.cn` | 需要 | 官方 API，有配额；已内置 0.6s 节流 + 429 退避 |
| 券商研报 | 东方财富 `reportapi.eastmoney.com` | 免 key | 列表 + 评级，仅供学习研究 |
| 概念板块 / 成分股 | 东方财富 F10 + `push2delay.eastmoney.com` | 免 key | 所属板块 + 板块成分股（按市值）+ 网络图 |

同花顺接口**不提供**：研报原文、分钟 K、tick、宏观数据、新闻公告原文。
